API 接口说明

提供两个核心接口，满足地图预览和数据解析需求

地图预览接口

/preview_geo

解析百度地图 geo 字符串并生成地图预览页面，支持三种坐标系统

geo_str 原始 geo 字符串（URL 编码） 必填
md5 用于生成唯一文件名的 MD5 值 必填
map_type WGS84/BD09/GCJ02 可选
name 自定义地域名称 可选
adcode 自定义区域编码 可选
curl "http://127.0.0.1:7862/preview_geo?geo_str=...&md5=abc123&map_type=WGS84&name=测试区域"

数据解析接口

/api/geo/parse

解析百度地图 geo 字符串并返回标准 GeoJSON 格式数据

geo_str 原始 geo 字符串（URL 编码） 必填
map_type WGS84/BD09/GCJ02 可选
name 自定义地域名称 可选
adcode 自定义区域编码 可选
curl "http://127.0.0.1:7862/api/geo/parse?geo_str=...&map_type=WGS84"

常见问题解答

关于使用中可能遇到的问题

什么是百度地图围栏 geo 字符串？
百度地图围栏 geo 字符串是百度地图 API 返回的区域边界坐标数据格式，包含多边形顶点坐标信息。本工具专门解析这种格式，并将其转换为标准的 GeoJSON 格式，便于在其他地图平台使用。
三种坐标系统有什么区别？
  • WGS84：国际标准坐标系统，Google Earth、GPS 等使用
  • BD09：百度地图专用坐标系统，在百度地图平台显示准确
  • GCJ02：火星坐标系，高德地图、腾讯地图等国内地图平台使用
如何获取百度地图 AK 和高德地图 Key？

需要分别注册百度地图开放平台和高德地图开放平台账号，创建应用后获取对应的 API Key。高德地图还需要获取安全密钥（security_code）用于接口签名验证。

生成的地图预览文件保存在哪里？

地图预览文件默认保存在当前工作目录的 `geo_maps` 子目录下，文件名基于提供的 MD5 值生成，确保每个围栏区域都有唯一的预览文件。

是否支持商业使用？

本项目采用 MIT 许可证，支持商业使用。但请注意，百度地图和高德地图的 API 调用需要遵守对应平台的使用条款和商业授权要求。
